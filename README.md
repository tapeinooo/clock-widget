# たぺいの時計（clock-widget）

時刻と日付を大きく出す、自分用の Android ホーム画面ウィジェット。

## 入れ方・更新

- Releases の最新の APK（`clock-widget-v2.0.<番号>.apk`）をスマホで開いて入れる。
- そのあとは、アプリを開いて「今すぐ更新を確認」（開いたときに新しい版があれば知らせが出る）。
- main に変更が入るたびに GitHub Actions が APK を作って Releases に出す（版の番号は自動）。

## 通信

- アプリの更新：GitHub の Releases だけ
