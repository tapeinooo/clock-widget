# たぺいの録音

壇上で話すときに使う、自分用の Android アプリ。

- **録音／録画**：音声のみ（m4a）か、映像＋音声（mp4、前面／背面カメラ、720p／1080p）。一時停止・再開できる。
  通知つきで常駐するので、他のアプリ（スライドやメモ）を開いても、画面を消しても録り続ける。
- **カメラのあたりに経過時間**：録っている間、画面上部のカメラ（パンチホール／ノッチ）の真下に経過時間を出す。
  他のアプリの上にも重なる。指で動かせて位置を覚える。表示中は画面が消えない。
  持ち時間を決めておくと、残りわずかで橙、超えたら赤になる。
- **切り出し編集**：一覧から選んで、始めと終わりを決め、その部分だけを新しいファイルとして保存する
  （0.1秒単位の表示、±1秒、今の位置を始め／終わりに、範囲の再生）。

一覧の各行の「削除」、または「選んで削除」でまとめて消せる。長押しで共有・名前の変更。

保存先は端末の「動画/StageRecorder」「音楽/StageRecorder」なので、ギャラリーなど他のアプリからも見える。

## 入れ方

push すると GitHub Actions で APK を作り、Releases の「たぺいの録音 最新版」（タグ `stage-recorder`）に載せる。
スマホでそこから `stage-recorder.apk` を開いて入れる。

一度入れたあとは、アプリを開くたびに新しい版を自動で確認し（30分に1回まで）、あれば上に「更新」ボタンが出る。
画面のいちばん下の「更新を確認」でも確かめられる。初めて更新するときだけ「この提供元のアプリを許可」をオンにする。
（リポジトリが公開されている必要がある。）

初回に、マイク（録画ならカメラも）・通知の許可と、
「表示を許可する（他のアプリの上に重ねる）」から重ねて表示する許可をする。

Android 10 以上。
